# First Area: Abandoned Bunker / New Bunker

The first playable area now has two connected sections.

## Abandoned Bunker
- Storage room with an access card
- Sleeping wing
- Security section and sealed door
- Dark interaction scare
- Radio signal scare
- First movement / "don't look back" scare
- Environmental messages and objectives

## New Bunker
- Generator room
- Control room
- Exit security
- Generator activation scare
- Monitor/hallway scare
- Exit sequence
- Area-complete state

## Controls
- WASD or Arrow Keys: move
- E or Enter: interact

The scares are implemented as short visual/audio-style cues rather than graphic imagery, so they can be expanded later with actual art, sound, animations, and cutscenes.
